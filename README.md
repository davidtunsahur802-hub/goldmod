# GoldMod (C++, x86) — для Extreme Injector

DLL на C++ вместо BepInEx-плагина. Игра 32-битная (IL2CPP), поэтому и DLL только **x86**.
Готовая сборка: `bin/GoldMod.dll`.

## Использование
1. Запусти игру, дождись меню.
2. Extreme Injector → выбери процесс игры → Add → `GoldMod.dll` → Inject.
3. В игре нажми **Home** — откроется меню (вкладки: Валюта / Игрок / Враги / Опции).
4. Лог: `GoldMod.log` рядом с DLL. Если что-то не работает — пришли этот файл.

## Сборка самому
Visual Studio (Developer Command Prompt):

    cmake -S . -B build -A Win32
    cmake --build build --config Release

(`-A Win32` обязателен — 64-битная сборка в 32-битную игру не загрузится.)

## Как устроено
| Было (BepInEx, C#)                        | Стало (C++)                                              |
|-------------------------------------------|----------------------------------------------------------|
| Harmony-патч `Controller.Awake`           | MinHook на `FMODUnity.RuntimeManager.Update` (главный поток, каждый кадр) |
| IMGUI через `FMODRuntimeManagerOnGUIHelper.OnGUI` | Dear ImGui поверх `Present` (D3D11, запасной D3D9). В этой сборке игры IMGUI (`GUI.Button`, `GUILayout.*`) вырезан, поэтому как есть он не переносится |
| Прямые вызовы классов игры                | `il2cpp_*` экспорты `GameAssembly.dll`; классы, поля и методы ищутся по имени/сигнатуре, а не по адресам — переживёт мелкие обновления |
| `Int`/`Float` (защищённые)                | кодируются **родными методами игры** (`Int`/`Float`), не своим алгоритмом |

Ввод игре не передаётся, пока меню открыто; курсор освобождается, а `PlayerController.m_controllPlayer`
временно ставится в `false` (отключается в «Опции»).

## Вкладки
- **Валюта** — установить GoldCount; награда за килл (одно число → голова и тело).
- **Игрок** — быстрый бхоп (пробел), ускоренная ходьба, высокий прыжок, ползунки скорости и высоты.
- **Враги** — WallHack, Аим (по умолчанию пока зажата ПКМ), снять лимит ботов.
- **Предметы** — выдать все предметы, разблокировать достижения (нужно открыть инвентарь / экран достижений).
- **Ключ** — записать любой ключ PlayerPrefs (число защищённое / число обычное / текст).
- **Опции** — жёсткая очистка всех PlayerPrefs (с подтверждением).
